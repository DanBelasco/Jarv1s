# Jarv1s :crystal_ball:

Sistema de monitoramento e atuação residencial com integração para smartphones.

Minha intenção aqui é APRENDER! e se possível desenvolver um sistema de acesso, monitoramento e alarme residencial. Com notificação e controle via celular e ou dispositivos do tipo "Alexa" e em uma central dentro da residência. essa residência possuirá vários dispositivos interagindo entre si como: sensores, relés, câmeras, terminais de acesso do tipo fechadura inteligentes, um totem que emite códigos de cores diferentes para cada tipo de alerta, e um terminal de acesso onde poderei acessar localmente as configurações. isso é o projeto em si finalizado. Mas primeiro pretendo desenvolver o sistema que controla tudo isso e interagir com a plataforma para rodar esse sistema que se chama Jarv1s.

Sim, parece muito ousado para um iniciante...
